# Screenshots

Put your GT Movies Store screenshots in this folder, then update the
`src` attribute of the matching `<img>` in `index.html`.

Suggested file names (one per section):

- `home-about.png`
- `movie-list.png`
- `movie-detail.png`
- `search.png`
- `signup-login.png`
- `reviews.png`
- `shopping-cart.png`
- `purchase-orders.png`
- `admin-panel.png`
- `report-review.png`
